# SaruNena AI

## Problem Statement

Many Sri Lankan farmers struggle to access
timely weather information, disease detection,
market prices, and farming recommendations.

## Solution

SaruNena AI is a multi-agent smart farming
assistant built using Agent Kernel concepts.

It provides:

- Weather monitoring
- Disease identification
- Market price assistance
- Farm risk assessment
- Personalized recommendations

## Agents

1. Memory Agent
2. Weather Agent
3. Disease Agent
4. Market Agent
5. Location Agent
6. Risk Agent
7. Recommendation Agent

## SDGs

- SDG 2: Zero Hunger
- SDG 13: Climate Action
